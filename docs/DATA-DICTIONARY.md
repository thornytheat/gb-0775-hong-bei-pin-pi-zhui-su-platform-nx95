# 称签卷联数据字典

| 原件 | 业务键 | 字段定义 |
|---|---|---|
| origins.csv | origin | `label` 产地批名，`available` 注册可用干料，`unit` 称量单位 |
| jobs.csv | work | `label` 工作批名，`measured` 工作批投入总秤，必须大于零，`unit` 称量单位 |
| inputs.csv | ticket | `work` 领料工作批，`source_kind` 为 origin 或 return，`source` 分别指产地批或返料卷联，`quantity` 投入干料，`unit` 称量单位 |
| outputs.csv | ticket | `work` 出料工作批，`kind` 为 pack、loss 或 return，`gross` 毛重，`tare` 皮重，`unit` 两个重量字段的单位 |
| receipts.csv | receipt | `ticket` 对应投入秤单，`source` 返料卷联，`received` 实领干料，`unit` 称量单位；可仅含表头，表示回执尚未到齐 |

每份 CSV 为 UTF-8，表头顺序可变，支持开头 BOM。每份原件上限 300 KB。重复表头和空行单计，记录保留来源表和物理行号。空串、`-`、`N/A`、`NULL`、`未知` 为缺项。登记表存在冲突即停止计算，明细秤单隔离后由工作批进入待证。`inputs`、`outputs` 和 `receipts` 允许仅有表头，作为尚未出示明细。API 提交可省略 receipts，省略时按空表处理。

称量单位是 mg、g、kg，归一为 g 后按有理数计算并存成分数字符串。净重 = 毛重 − 皮重。秤单键按原件表独立去重，单位归一后关键字段相同保留最早行。冲突同键行均隔离。质量相同但毛重、皮重分解不同仍判冲突。

同一来源的申请先合计，超出容量整组待证，绝不按提交顺序先到先认（先到先认会把错料一路算进下游）。原料超领无回执通道，整组隔离。返料超领时整组挂 `RECEIPT_MISSING`，等每张申请秤单的实领回执到齐：回执来源必须与申请卷联一致（`RECEIPT_SOURCE`），且实领合计大于零并不超过卷净重，裁决才放行；部分回执、实领合计仍超卷重时继续整组待证。放行后按实领额（而非申请额）建边与核销，实领与申请不符留 `RECEIPT_VARIANCE` 信息痕：该码不阻断签发、不向上游传播，差额由实领解释的工作批仍判已核，守恒账按实领额勾稽。晚到的回执补齐后重新试算即生成新归档；已签发的旧归档凭原件指纹仍可核验，重跑同一份材料命中同一指纹，不新增签件。返料图以已通过来源与容量校验的投入建边。循环节点保留循环见证，依赖待证来源的下游同步待证。通过批的实际投入按产地质量占比等比例分给灌装、返料、损耗及未下线余料。耗用返料从原卷净额扣减，来源池申请额、实领额与最终核销额分别记录。

每批按总秤核对灌装、损耗、余量及待证。余量包含工作批余料和该批发出的返料，仓内复核只加未领返料。待证批总秤进入逐批待证账，可信原料核销另按合格批推导。同一归档内按包装号追溯净重和产地组成。文件指纹和规则版本构成归档号，复算核对原件、结果摘要和运行标识。

当前规则采用同批均质和干料重量基准。未接入秤机、水分校正、温度曲线或跨场次库存调拨。
